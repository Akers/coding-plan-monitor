# 使用手册

本文档介绍 Coding Plan Monitor 的日常使用方式，包括悬浮面板、托盘菜单、配置窗口和 OAuth 授权流程。

## 1. 启动应用

开发模式下执行：

```bash
npm run tauri dev
```

应用启动后会显示一个无边框置顶的悬浮面板，并在系统托盘区显示应用图标。

## 2. 悬浮面板

悬浮面板用于展示当前供应商的额度信息。

### 主要区域

- 顶部：供应商标签栏，可手动切换供应商。
- 中部：额度维度列表，显示进度条、百分比、已用/总额和单位。
- 底部：最后刷新时间、锁定、最小化和设置入口。

### 交互操作

- **拖拽移动**：面板未锁定且未启用点击穿透时，可拖拽面板。
- **四边吸附**：拖拽到屏幕边缘附近时，面板会自动贴边。
- **最小化**：面板贴边后可收起到屏幕边缘。
- **展开**：点击收起状态的展开按钮恢复面板。
- **右键刷新**：在面板上打开右键菜单，选择“刷新”可立即刷新额度数据。
- **打开配置**：点击底部设置按钮或托盘菜单中的“配置窗口”。

## 3. 系统托盘

托盘图标提供快速入口和状态提示。

### 托盘状态

- 正常：所有启用供应商额度低于提醒阈值。
- 警告：任一供应商任一额度维度达到提醒阈值。
- 错误：所有启用供应商刷新失败。

### 托盘菜单

- 显示/隐藏面板
- 打开配置窗口
- 退出应用

## 4. 配置窗口

配置窗口包含三个选项卡：

1. **通用设置**：刷新间隔、轮播间隔、面板背景色、透明度、吸附边、锁定、自启动。
2. **额度显示**：阈值、进度条颜色、限额提醒开关和提醒阈值。
3. **供应商管理**：启用/禁用供应商，填写 API Key 或进行 OAuth 授权，验证供应商配置。

点击“保存”后配置会写入本地配置文件，并通知悬浮面板重新加载配置；点击“取消”会丢弃未保存的修改。

## 5. 供应商授权

### API Key 供应商

在供应商管理中输入 API Key，然后点击“验证”。验证通过后保存配置。

### OAuth 供应商

点击“登录授权”后，应用会启动本地临时回调服务并打开浏览器。授权成功后，供应商回调到本地地址，应用会保存 token 并关闭回调流程。

默认 OAuth 回调端口为 `9527`，可在配置中调整。

## 6. 限额提醒

当启用限额提醒后，系统会在刷新数据时检测额度百分比。达到提醒阈值时，会发送系统通知并更新托盘状态。

## 7. 日志与配置文件

- 配置文件：`~/.config/coding-plan-monitor/config.json`
- 日志目录：由 Tauri log 插件写入系统应用日志目录

请不要公开分享配置文件，因为其中可能包含 API Key 或 OAuth Token。
